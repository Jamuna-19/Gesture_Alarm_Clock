# Gesture-Alarm-Clock

The Gesture Alarm Clock is an ESP32-based smart alarm clock that combines Bluetooth control, real-time clock monitoring, and gesture sensing. The alarm can be set through a mobile device, and a hand gesture can be used to stop the buzzer.

## Features
- ESP32-based smart alarm clock
- Bluetooth-based alarm setting
- DS3231 real-time clock
- 16×2 I2C LCD time display
- APDS9960 gesture sensor
- Gesture-based alarm control
- Buzzer alarm notification
- Real-time clock monitoring
